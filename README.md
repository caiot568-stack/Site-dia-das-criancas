## Visão geral

Página web temática sobre o **Dia das Crianças (12/10)**, desenvolvida como projeto prático da disciplina de **Desenvolvimento front-end para web**, no curso de **Sistemas De Informação**.

O projeto resolve o problema de apresentar, de forma organizada e visual, informações sobre a data: como ela surgiu, brincadeiras tradicionais, educação e direitos da criança. Tudo em uma interface **responsiva**, que funciona em celular, tablet e desktop.

### Principais recursos

- Barra de navegação responsiva com menu suspenso (*dropdown*) e busca
- Carrossel de imagens com reprodução automática
- Seções com *accordion* (História, Brincadeiras tradicionais, Direitos da criança)
- Layout adaptável com o sistema de grid do Bootstrap

## Como executar localmente

Não há dependências para instalar: é um site estático.

```bash
# 1. Clone o repositório
git clone https://github.com/caiot568-stack/Site-dia-das-criancas.git

# 2. Entre na pasta
cd site-dia-das-criancas

# 3. Abra o index.html no navegador
#    (dê duplo clique no arquivo, ou use a extensão Live Server do VS Code)
```
